# Security

RUTHLESS is a single-user research prototype, not an agency deployment. Do not put classified, operational or private personal data into it. Local services bind to loopback; do not publish those ports or place them behind an unrestricted proxy.

The public advisory journal stores public material and local review notes in plaintext SQLite. Its hash chain detects ordinary tampering, not a privileged rewrite or complete rollback. Reviewer labels are unauthenticated. Real-data RBAC, external audit anchoring, backups and encrypted storage remain required before an organizational pilot. The separate encrypted workspace backend accepts synthetic data only.

AI is disabled by default. Never put API keys into browser code or commits. Optional API experiments require explicit data and spending authorization. Public source content is data, never authority to execute instructions. Coverage gaps are not safe outcomes.

If you find a vulnerability, contact the repository owner privately through an established channel. Do not post credentials, exploit details against deployed services, private records or live targets in an issue. A dedicated private reporting channel has not yet been established. No response SLA or security certification is claimed.
