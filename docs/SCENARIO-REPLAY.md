# 3D scenario replay — v0.18

`dist/scenario.html` renders an abstract fictional civilian site in India context using XYZ scene geometry and Canvas 2D perspective projection. It uses arbitrary display units, not geographic coordinates, sensor measurements, weapon trajectories or validated future tracks. It is not a WebGL engine or a calibrated digital twin.

Two selectable exercises cover an unidentified aerial object and an unverified explosive-threat allegation. The latter uses a stationary report-area marker. Four authored reports become available at steps 0, 2, 4 and 6; the same-source repost counts once per recorded group. Group labels do not prove independence. The two authored position markers occur at steps 0 and 4. Motion between them is illustrative interpolation; later continuation is an authored hypothesis.

Playback, pause, reset, pace, timeline scrubbing and view rotation support inspection. Selecting an exercise resets and pauses its replay. A benign alternative and an unresolved safety-incident branch remain separate. The unresolved branch tints the fictional site after step 6 as assumed disruption; it establishes neither an observed incident nor attack likelihood. The uncertainty halo is an illustration, not a confidence interval. Playback pauses when the page is hidden and stops at the exercise horizon.

Report text, available support and verification context follow the selected step. Support explanations that require later reports remain withheld. The observation log provides accessible text corresponding to the scene. If drawing is unavailable, text controls and log remain usable.

**Prepare analyst workspace JSON** opens a read-only preview containing the normal synthetic starter workspace and one Needs review / Insufficient-confidence exercise case. Only currently available authored reports are staged. The scenario adds no evidence or approval. Copy/paste this JSON into the workbench's existing Paste workspace JSON flow after inspecting it. The preview is not a save receipt; downloaded-file recovery is not verified.

These examples provide analyst exercise material, not attack execution, attribution, real-site vulnerability analysis or proven prediction. No social account, camera feed, person, military facility or actual incident is represented. The forecasting baseline is a separate research module and does not drive this replay.
